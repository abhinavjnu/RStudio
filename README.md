# RStudio

## Getting Started with GitHub Codespaces

This repository is configured to run [RStudio Server](https://posit.co/products/open-source/rstudio-server/) inside a [GitHub Codespace](https://github.com/features/codespaces).

### Launch a Codespace

1. Click the green **Code** button at the top of this repository.
2. Select the **Codespaces** tab.
3. Click **Create codespace on main** (or your preferred branch).

### Access RStudio

Once the Codespace is ready, RStudio Server starts automatically on port **8787**. A browser tab will open with the RStudio IDE—no login required.

If the tab does not open automatically, open the **Ports** panel in the Codespace and click the globe icon next to port 8787.
